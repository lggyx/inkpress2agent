# InkPress UI 方案「白纸代码 · 色卡」v7

> 2026-11-14 傍晚 · 响应用户新指令：偏白底色 + 代码块/数字雨背景基调 + 颜色卡片风格
> 定位：不是推翻，是把历史裁决中"对"的元素（浅白底 v4 ✓ / 颜色卡 v3 ✓ / 零渐变零辉光铁律）+ 新元素（代码质感）合成一版

---

## 一、一句话概念

**"代码写在白纸上，卡片浮在代码上"**——整站像一页摊开的工程师手稿：底色是纸白，背景纹理是极淡的代码流与数字，前景是高饱和实色的内容卡片。理性（代码）为底，感性（色卡）为面。

## 二、配色系统

| 层 | Token | 值 | 说明 |
|---|---|---|---|
| 底 | `--bg` | `#FBFBF9` | 暖纸白（不用纯白，减刺眼） |
| 代码纹理 | `--code` | `rgba(24,24,27,.05~.07)` | 墨色极低透明度，印代码字符/行号/数字 |
| 卡面 | `--card` | `#FFFFFF` | 纯白卡，1px 描边 `rgba(0,0,0,.09)` |
| 墨 | `--ink` | `#1A1A1E` | 正文标题 |
| 卡1 文章 | `--c-indigo` | `#4F46E5` | 靛蓝 |
| 卡2 进化 | `--c-orange` | `#EA580C` | 橙 |
| 卡3 检索 | `--c-teal` | `#0D9488` | 青绿 |
| 卡4 图谱 | `--c-violet` | `#7C3AED` | 紫 |
| 卡5 状态 | `--c-lime` | `#65A30D` | 草绿 |
| 卡6 流量 | `--c-rose` | `#E11D48` | 玫红 |
| 强调 | `--acc` | 跟随当前卡片色 | 单页只亮一个色系 |

**纪律**：同屏可见色相 ≤ 3（铁律第 3 条）；卡片全是实色，零渐变零辉光（铁律 1）；代码纹理是"纸的纹理"不是"赛博雨"，透明度压到 5-7%，绝不抢内容。

## 三、代码背景基调的三种做法（按实现成本递增，可混用）

| 方案 | 做法 | 观感 | 成本 |
|---|---|---|---|
| **T1 静态手稿层**（推荐基底） | 预生成真实代码片段（本项目真实源码：ArticleService.java / render-rollup.js 等）以极淡文字平铺在 body 背景，带行号、带语法高亮的灰阶版 | "工程师手稿"，静态但真实 | 半天 |
| **T2 数字锚点流** | 在 T1 上叠加少量"有意义的数字"高亮（如 29.9%、7/7、100%、35 篇），偶尔在视口边缘缓慢位移 | 与产品指标呼应，有生命感 | +2h |
| **T3 输入态光标** | 每屏一个闪烁光标块（1 个，非常克制），暗示"正在书写" | 点题"Agent 正在写" | +1h |

落地建议：**T1 全站 + T2 首页/进化页 + T3 仅首页 hero**。纹理用 CSS `background-image: repeating-linear-gradient` + 若干绝对定位 `<pre>` 实现，性能零负担（无 canvas 动画循环）。

## 四、颜色卡片组件语言

```
┌─────────────────────────┐
│ ▌Workbench        #4F46E5│  ← 顶部：mono 大写标签 + 色号（工程感）
│                         │
│  AI 创作台              │  ← 卡标题：28-34px 黑体 800
│  三栏创作流 · 命令卡     │  ← 描述一行
│                         │
│  6 模板        ◉ 35 篇  │  ← 底行：数值 + 状态点
└─────────────────────────┘
   ↑ 左侧 6px 实色色条（继承卡色），白卡身
```

- **卡色即语义**：一张卡一种色，色条+标签+数字用同色，卡身永远白
- 悬停：卡整体上浮 4px + 色条加宽到 8px（唯一动效），无阴影扩散无辉光
- 关键数字用 **tabular 等宽** + 卡色，大号（48-64px）
- 交互态：按压 1px 下沉；选中卡描边变卡色 2px

## 六、与 PPT「飞轮」叙事的对齐

这版 UI 本身就是叙事道具：
- **白纸 = 人的阅读面**，**代码底纹 = Agent 的工作现场**——"人类线和 Agent 线在同一张纸上"
- 卡上的真实数字（35 篇 / 7/7 / 29.9%→1.2%）全部来自实测，评委扫一眼就有数据信任
