## 各维度详注

### 1. CMS 市场格局（W3Techs 实时）
WordPress 全网站占比 39.5%、CMS 市场份额 58.2%；Shopify 7.9%、Wix 6.1%、Squarespace 3.6%。Ghost/Jekyll/Halo 等现代化方案份额各不足 0.1%~0.5%——**主流方案技术形态老化（PHP 单体）是结构性缺口**。

### 2. 博客系统生态（GitHub API 实时）
| 项目 | Stars | 技术 | 创建 | AI 内建 |
|------|-------|------|------|--------|
| Hugo | 90,380 | Go | — | 无 |
| Ghost | 55,679 | TS | 2013 | 无 |
| Jekyll | 51,745 | Ruby | — | 无 |
| Hexo | 41,779 | TS | — | 无 |
| Halo | 40,113 | Java | 2018 | 依赖插件 |
| Typecho | 12,458 | PHP | — | 无 |

**六大现代化方案合计 29 万 star，无一家内建 AI** —— 差异化空间量化。

### 3. 核心论文引用（Semantic Scholar 实时）
Attention 201,377（2017）/ GPT-3 66,129（2020），合计 26.7 万。RAG 与特征哈希两篇限流未验证（B 级，正文仅定性引用）。

### 4. AI 服务成本（智谱定价实时）
GLM-4-Flash 输入输出全免费；Embedding-3 为 0.5 元/百万 tokens，38 篇全文约 60 万 tokens，全库向量化 **0.3 元**。开发期 AI 总成本 < 1 元。

### 5. 技术栈版本（endoflife 实时）
Spring Boot 3.3（项目采用）OSS 支持 2025-06 结束，最新为 4.1——答辩口径：选型时点的稳定版，毕设周期内正常使用。Vue 3.5.44、Node 26 LTS 均为当前活跃版本。

### 6. 开发者生态（Stack Overflow 2025 调查）
Web 框架使用率：Node.js 48.7%、React 44.7%、Vue 17.6%、Spring Boot 14.7%。数据库：PostgreSQL 55.6%、MySQL 40.5%、Redis 28%（同比 +8pp）。工具：Docker 71.1%（同比 +17pp，全场最大增幅）、Vite 25.4%。**项目全栈选型均在主流使用率区间**。

### 7. npm 月下载量（npm API 实时，2026-10-05~11-03 窗口）
Vite 7.81 亿、React 7.57 亿、Express 5.91 亿、Vue 7236 万。**Vue 与 React 的下载量差约 10 倍**——答辩被问"为什么不用 React"时的诚实口径：React 生态更大（数据如实展示），选 Vue 因组合式 API 对单人毕设的可维护性更优，且两者在 SO 调查使用率差距（44.7 vs 17.6）远小于下载量差距（间接依赖 vs 直接依赖的统计口径差异）。

### 8. 中国互联网与 AI（CNNIC 第 57 次报告，截至 2025-12）
网民 11.25 亿（普及率 80.1%）；**生成式 AI 用户 6.02 亿、同比增长 141.7%、普及率 42.8%**——选题时代背景的最权威背书：AI 应用已从尝鲜进入大众普及阶段。

### 本地实测 A：Redis 基准（docs/research/redis_benchmark.py）
- 管线批量：SET 50,489 / GET 71,159 / **INCR 81,845 ops/s**
- 单次 GET：p50 = 0.33ms，p99 = 0.96ms
- **意义**：浏览量高频写走 Redis 的设计依据——计数吞吐 8 万级，单次亚毫秒，1 分钟回写周期内可承接 485 万次浏览（81845×60）

### 本地实测 B：语义检索基准（docs/research/semantic_benchmark.py）
- 文章分页（MySQL 直查）：76~118ms
- 语义检索：首轮 332ms（含 Redis 逐篇加载向量的冷启动），热态 172~197ms
- 相关推荐：热态 161~180ms
- **意义**：512 维本地向量全库余弦在 38 篇规模下热态 < 200ms（含 HTTP 往返），满足交互需求；冷热差异指明优化方向（向量常驻内存/预加载）

## 评述链（PPT 现状页骨架）

市场存在（WP 58.2%）→ 方向正确（六大现代化方案 29 万 star）→ 缺口明确（无一家内建 AI）→ 技术成熟（论文 26.7 万引用 + AI 用户 6.02 亿）→ 成本趋零（免费 + 0.3 元）→ 性能可行（Redis 8 万 ops/s + 检索 <200ms）→ **切入空间：前后端分离 + AI 一体化的轻量博客系统**
