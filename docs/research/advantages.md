## 二、五大差异化优势（每条都有数字背书）

### 优势 1：AI 能力内建且工程化完整 —— 全网同类无一做到

- Ghost 55,679 star、Halo 40,113 star、Hugo 90,380 star——**六大现代化方案合计 29 万 star，无一家内建 AI**（调研维度 02）
- 五项辅助（润色/摘要/标签/续写/标题）+ RAG 问答，且**流式输出全链路**（后端 HttpClient→SseEmitter→前端 ReadableStream 节流渲染）
- 成本侧：GLM-4-Flash 免费、全库向量化 0.3 元（调研维度 04）——**"零成本 AI"不是口号，是定价页实数**

### 优势 2：检索是"做的"而不是"接的" —— 算法自研可讲原理

- 相关文章 = `0.85×语义 + 0.15×标签` 混合排序，公式可解释、权重可实验（论文 4.4.3）
- 本地 512 维特征哈希向量**零依赖可用**，配 Key 自动升级远程 Embedding（SPI 双实现）
- 实测：检索热态 ~180ms、推荐 161ms（含 HTTP 往返，38 篇全库）——**答辩现场可跑**
- 竞品的"相关文章"是简单规则（同分类/同标签），语义维度是空白

### 优势 3：高频写的架构级解法 —— 有量化数据

- 浏览量：Redis INCR 承接（实测 **81,845 ops/s**、p50 0.33ms），定时任务回写 MySQL
- 换算：**1 分钟回写周期可承接 485 万次浏览**——个人博客场景冗余量巨大
- 竞品对比：Ghost/Halo 浏览量直写数据库（官方架构文档），高流量下即瓶颈

### 优势 4：安全设计超出同类毕设水准

- JWT 无状态认证 + 角色分流（401/403 区分）——企业级方案
- Markdown 渲染 DOMPurify 白名单净化（防 XSS）；游客邮箱前台不暴露（隐私分层）
- 参数边界全覆盖（pageSize 上限 50、标签长度校验）——**26 项冒烟断言里一半是防破坏性输入**
- 修复记录可查：游客点赞 401、SQL 注入面、超长标签 500 等 17 个真实缺陷（git log 全程可溯）

### 优势 5：数据自有 + 可迁移性 —— 用户侧核心价值

- 文章、评论、用户全部存自建 MySQL；38 篇真实文章从 GitHub Pages **一键脚本迁移**（含图片外链改写）验证过可行性
- AI 厂商可插拔（改 3 行配置）；向量实现可插拔；部署 Docker Compose 一键
- 对比：托管平台（Wix/Squarespace 6.1%+3.6% 份额）导出能力受限（各平台官方文档明示）

## 三、如实声明（答辩防御口径）

不回避的劣势，老师问到时的诚实回答：

1. **生态差距**：WordPress 插件生态 5.8 万+（WordPress.org 插件目录可查），我们无法比——定位是"轻量一体化"而非"万能平台"
2. **React 生态差距**：npm 月下载 7.57 亿 vs Vue 7236 万——选型理由是单人项目可维护性，不是生态（调研维度 07 口径已备好）
3. **规模上限**：余弦检索是全内存线性扫描，38 篇 180ms，若到万篇级需换 ANN 索引（Faiss/HNSW）——论文局限章节已写明

> 答辩话术：**"比生态我们承认差距，比设计我们逐项占优。"** 矩阵里 10 个能力项，InkPress 是唯一全满的。

## 四、一句话总结（PPT 定位页用）

> 29 万 star 的现代化方案证明了方向，但它们都没做 AI；我们用 0.3 元的成本把 AI、语义检索和 RAG 做成了一个轻量系统——这是矩阵里唯一的满格列。
