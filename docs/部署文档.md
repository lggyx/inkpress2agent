# InkPress 部署文档

## 一、本地开发环境

### 1. 环境要求

| 软件 | 版本 | 说明 |
|------|------|------|
| JDK | 17+ | 后端运行环境 |
| Maven | 3.8+ | 后端构建 |
| Node.js | 20+ | 前端构建 |
| MySQL | 8.0 | 主数据库 |
| Redis | 7.x | 缓存与计数 |

MySQL 与 Redis 推荐直接用 Docker 启动：

```bash
docker compose up -d mysql redis
```

首次启动 MySQL 会自动执行 `inkpress-server/src/main/resources/db/init.sql`，完成建库、建表、写入种子数据；管理员账号（admin / admin123）由后端首次启动时自动创建。

### 2. 启动后端

```bash
cd inkpress-server
mvn spring-boot:run
```

默认端口 8080。常用配置（application.yml 或环境变量）：

| 配置 | 环境变量 | 默认值 |
|------|---------|--------|
| 数据库地址 | `MYSQL_HOST` / `MYSQL_PORT` | localhost / 3306 |
| 数据库账号密码 | `MYSQL_USERNAME` / `MYSQL_PASSWORD` | root / root123 |
| Redis 地址 | `REDIS_HOST` / `REDIS_PORT` | localhost / 6379 |
| JWT 密钥 | `JWT_SECRET` | 开发默认值（生产必须覆盖） |
| AI 服务地址 | `AI_BASE_URL` | 智谱开放平台 |
| AI API Key | `AI_API_KEY` | 空（未配置时 AI 功能提示不可用） |
| AI 模型 | `AI_MODEL` | glm-4-flash |
| 初始管理员密码 | `INKPRESS_ADMIN_PASSWORD` | admin123 |

### 3. 启动前端

```bash
cd inkpress-web
npm install
npm run dev      # 开发模式，5173 端口，/api 代理到 8080
npm run build    # 生产构建，输出 dist/
```

## 二、Docker Compose 一键部署

```bash
cd inkpress-web && npm run build && cd ..
docker compose up -d --build
```

启动后服务拓扑：

| 容器 | 端口 | 说明 |
|------|------|------|
| inkpress-web (Nginx) | 80 | 前端静态资源 + 反向代理 |
| inkpress-server | 8080 | Spring Boot 后端 |
| inkpress-mysql | 3306 | 数据库（数据卷持久化） |
| inkpress-redis | 6379 | 缓存 |

访问 http://localhost 即可使用。接口文档 http://localhost/doc.html 经由 Nginx 代理。

**注意**：`docker-compose.yml` 中的 `AI_API_KEY` 与 `JWT_SECRET` 需要替换为真实值后再上线。

## 三、云服务器部署（Linux）

1. 安装 Docker 与 Docker Compose，其余步骤与上面相同。
2. 域名与 HTTPS：在服务器 Nginx 外层再加一层证书（或直接修改本仓库 `nginx.conf`，增加 443 监听与证书路径）。
3. 数据备份：`docker exec inkpress-mysql mysqldump -uroot -proot123 inkpress > backup.sql`。
4. 更新发布：

```bash
git pull
cd inkpress-web && npm run build && cd ..
docker compose up -d --build
```

## 五、常见问题

**Q: 后端启动报数据库连接失败？**
确认 MySQL 已启动、账号密码正确、`inkpress` 库已创建（首次启动脚本会自动建库；手动初始化请先执行 init.sql）。

**Q: AI 润色提示"AI 服务未配置"？**
设置 `AI_API_KEY` 环境变量后重启后端。

**Q: 前端登录后一直跳回登录页？**
生产部署时前后端必须同域（经 Nginx 反向代理），或保持本仓库默认的 `/api` 路径转发方式。

**Q: 评论提交后前台看不到？**
系统默认开启评论审核（`inkpress.comment.audit: true`），需管理员在后台「评论管理」中通过后展示。
