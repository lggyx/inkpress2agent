## 二、接口压测（50 并发，开题硬指标）

工具：`docs/perf/loadtest.py`（Python threading，50 线程 × 每线程 4 请求/端点，同时起跑）
原始数据：`docs/load-test-result.json`

| 核心接口 | P50 | **P95** | P99 | 错误率 | 吞吐 | 达标（P95<500ms，err<1%） |
|---|---|---|---|---|---|---|
| 文章列表 `/api/articles` | 99.8ms | **372.9ms** | 423.9ms | 0% | 293.9 rps | ✅ |
| 文章详情 `/api/articles/{id}` | 57.6ms | **87.5ms** | 93.4ms | 0% | 742.4 rps | ✅ |
| 站内检索 `/api/search` | 158.1ms | **221.4ms** | 246.5ms | 0% | 273.3 rps | ✅ |

- 优化记录：文章列表装配由逐行查询（N+1，P95 796ms ❌）重构为整页 3 条批量查询（分类/关联/标签），P95 降至 373ms ✅。
- 附注：压测期间曾暴露 `IPage.convert` 原地替换 records 导致的空指针（映射 null 后 getRecords 全 null），已改为手工组装响应页——该坑已记入开发记忆。

## 三、首屏加载（开题指标 ≤ 2 秒）

工具：`docs/perf/firstscreen.py`（SSR TTFB 取 3 次最优 + 关键资源体积）

| 页面 | SSR TTFB（热缓存） | 说明 |
|---|---|---|
| 首页 `/`（ISR 60s） | **25.4ms** | 冷渲染 P95 612ms，ISR 命中后 25ms |
| 文章页 `/article/{id}`（ISR） | **40.1ms** | 同上 |
| 图谱页 `/graph`（SPA） | 10.2ms | 壳页 |

首页关键资源：1 个主 JS chunk（~1.1MB，gzip 传输），局域网/CDN 下首屏整体 < 1s，**满足 ≤ 2s 目标**；公网 5Mbps 带宽估算约 1.5s，仍在指标内。

## 四、检索对比实验（RRF）

工具：`docs/perf/rrf_experiment.py`，数据：`docs/rrf-experiment-result.json`

- 5 组查询词 × bm25 / vector / hybrid 三模式，记录有效模式、延迟、Top5 结果。
- **当前状态**：embedding 槽未配置第三方 Key，`vector` 臂按设计自动降级为 bm25（响应 `mode` 字段如实标注）；`hybrid` 为 BM25 + 空向量臂的 RRF，与纯 BM25 排序一致。
- **配置 Key 后重跑本脚本**即可产出真实三路对比数据（脚本已就绪，无需改动）。建议论文实验前在语料库中补充 15~20 篇文章，使 Top5 对比有区分度。
