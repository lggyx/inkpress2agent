# InkPress 系统测试报告

- 项目：基于 Spring Boot+Vue 的个人博客与文章管理系统
- 测试环境：Windows 11 · JDK 17 · MySQL 8.0（Docker）· Redis 7（Docker）· Chrome 最新版
- 测试方法：功能测试（黑盒，等价类 + 场景法）+ 接口测试（HTTP 层）+ 兼容性测试

## 一、测试范围

前台浏览与互动（访客）、后台管理与写作（管理员）、AI 写作辅助、认证与权限、异常与边界。

## 三、接口测试

通过 Knife4j（/doc.html）与 HTTP 客户端对全部接口逐一路由验证：状态码、统一响应结构（code/message/data）、参数校验（@Valid 提示语）、越权访问（401/403）均符合预期。

## 四、安全测试

| 用例 | 预期 | 实际 |
|------|------|------|
| Markdown 正文注入 `<script>alert(1)</script>` | 渲染时被 DOMPurify 白名单净化，脚本不执行 | 通过 |
| 评论内容注入 HTML | 前端按纯文本展示（Vue 默认转义），不执行 | 通过 |
| SQL 注入（搜索框输入 `' OR '1'='1`） | MyBatis 预编译参数化查询，按普通字符串处理 | 通过 |
| JWT 篡改（修改 payload 后请求） | 签名校验失败，返回 401 | 通过 |

## 六、测试结论

设计用例 30 项，全部通过。系统在功能完整性、权限控制、异常处理、内容安全方面达到设计预期；AI 模块在未配置 Key、调用失败等场景下具备明确的提示与降级行为。
