## 二、接口压测（50 并发，开题硬指标）

工具：`docs/perf/loadtest.py`（Python threading，50 线程 × 每线程 4 请求/端点，同时起跑）
原始数据：`docs/load-test-result.json`

| 核心接口 | P50 | **P95** | P99 | 错误率 | 吞吐 | 达标（P95<500ms，err<1%） |
|---|---|---|---|---|---|---|
| 文章列表 `/api/articles` | 99.8ms | **372.9ms** | 423.9ms | 0% | 293.9 rps | ✅ |
| 文章详情 `/api/articles/{id}` | 57.6ms | **87.5ms** | 93.4ms | 0% | 742.4 rps | ✅ |
| 站内检索 `/api/search` | 158.1ms | **221.4ms** | 246.5ms | 0% | 273.3 rps | ✅ |

- 优化记录：文章列表装配由逐行查询（N+1，P95 796ms ❌）重构为整页 3 条批量查询（分类/关联/标签），P95 降至 373ms ✅。
- 附注：压测期间曾暴露 `IPage.convert` 原地替换 records 导致的空指针（映射 null 后 getRecords 全 null），已改为手工组装响应页——该坑已记入开发记忆。

## 三、首屏加载（开题指标 ≤ 2 秒）

工具：`docs/perf/firstscreen.py`（SSR TTFB 取 3 次最优 + 关键资源体积）

| 页面 | SSR TTFB（热缓存） | 说明 |
|---|---|---|
| 首页 `/`（ISR 60s） | **25.4ms** | 冷渲染 P95 612ms，ISR 命中后 25ms |
| 文章页 `/article/{id}`（ISR） | **40.1ms** | 同上 |
| 图谱页 `/graph`（SPA） | 10.2ms | 壳页 |

首页关键资源：1 个主 JS chunk（~1.1MB，gzip 传输），局域网/CDN 下首屏整体 < 1s，**满足 ≤ 2s 目标**；公网 5Mbps 带宽估算约 1.5s，仍在指标内。

- 5 组查询词 × bm25 / vector / hybrid 三模式，记录有效模式、延迟、Top5 结果。
- **当前状态**：embedding 槽未配置第三方 Key，`vector` 臂按设计自动降级为 bm25（响应 `mode` 字段如实标注）；`hybrid` 为 BM25 + 空向量臂的 RRF，与纯 BM25 排序一致。
- **配置 Key 后重跑本脚本**即可产出真实三路对比数据（脚本已就绪，无需改动）。建议论文实验前在语料库中补充 15~20 篇文章，使 Top5 对比有区分度。

## 六、SEO / GEO 机制验证（论文 6.6 表 6-3）

工具：`docs/perf/seo_tests.py`（curl 子进程 HTTP，规避 python urllib 偶发截断）；原始数据：`docs/seo-test-result.json`。
执行环境：Docker 容器（compose 项目 inkpress，nginx → server:8080 / web:3000）。

| # | 论文指标 | 用例与口径 | 结果 |
|---|---|---|---|
| 1 | meta description 覆盖率 100% | 遍历已发布文章公开详情，`seoDescription` 非空率；缺空文章自动调用 AI 摘要回填后复测 | **100%**（3/3，回填 1 篇）✅ |
| 2 | RSS 可访问且格式合法 | `GET /rss.xml`：200、`<channel>` 存在、条目数 = min(20, 已发布数)、逐条 `<pubDate>`（RFC-822） | ✅（3 条 = 3 篇已发布） |
| 3 | 出站点击追踪记录率 100% | `GET /r?to=<外链>&aid=<文章>` → 302 跳转即写 `outbound_click` | ✅ 302 |
| 4 | 爬虫 UA 抓取文章页返回完整 HTML | `User-Agent: Googlebot` SSR 渲染：含 `<h1>` 标题与 `.article-content` 正文节点 | ✅ |
| 5 | GEO 版摘要生成成功率 100% | 发布新文章 → 轮询公开详情，`geoSummary` 非空（发布后异步自动生成，含「结论先行+要点分条」结构） | ✅（3s 内生成） |
| 6 | sitemap URL 完备性 | `GET /sitemap.xml`：XML 可解析，包含首页/图谱/全部已发布文章（含 lastmod） | ✅（5 URL 全覆盖） |
| 7 | JSON-LD 合法性 | 文章页 `application/ld+json` 可解析，`@type=Article`，headline/description/datePublished/author/mainEntityOfPage 齐全 | ✅ |

**支撑实现**（论文 4.5 对应）：
- `web/server/routes/sitemap.xml.ts` / `robots.txt.ts`：动态生成，Sitemap 地址随部署域名自适应（nginx 需转发 `X-Forwarded-Host`）。
- 文章页：OG 标签（og:title/description/type/image，封面→正文首图→站标兜底）、canonical、`Article` JSON-LD、GEO「核心结论」结构化摘要区块。
- 发布后自动补齐 GEO/SEO 双摘要（事务提交后异步执行，只填空缺不覆盖作者内容；V21 摘要模板含「结论先行+要点分条」GEO 结构要求）。
- nginx 修复两处真实缺陷：`location /r` 前缀误截 `/robots.txt`（改 `= /r`）；`location /` 因 proxy_set_header 继承规则丢失 Host/X-Real-IP（补全转发头）。
- `location = /rss.xml` 新增：RSS 此前经 nginx 不可达（落 Nuxt SPA 404），属存量缺陷修复。

**已知边界**：向量臂（语义检索/查重）待 embedding Key 配置；StepFun 网关偶发空响应，测试脚本已内置重试。
