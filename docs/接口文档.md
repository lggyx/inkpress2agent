# InkPress 接口文档

完整在线文档（Knife4j / OpenAPI 3）：启动后端后访问 **http://localhost:28080/doc.html**，右上角 Authorize 填入 `Bearer <token>` 可在线调试。

所有接口统一返回：

```json
{ "code": 200, "message": "操作成功", "data": ... }
```

认证方式：请求头 `Authorization: Bearer <JWT>`，令牌有效期 7 天。

## 一、认证 `/api/auth`

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | /api/auth/login | 登录，返回 token 与用户信息 | 公开 |
| POST | /api/auth/register | 注册（用户名 3-20 位字母数字下划线） | 公开 |
| GET | /api/auth/me | 当前登录用户信息 | 登录 |

## 二、文章 `/api/articles`（前台公开）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/articles/page | 分页，参数：pageNum、pageSize、keyword、categoryId、tagId |
| GET | /api/articles/hot | 热门文章 TOP N（Redis 缓存 5 分钟） |
| GET | /api/articles/archives | 归档时间线（按年分组） |
| GET | /api/articles/{id} | 文章详情，同时触发浏览计数 |
| POST | /api/articles/{id}/like | 点赞（按登录用户或 IP 去重），返回最新点赞数 |

## 三、文章管理 `/api/admin/articles`（仅管理员）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/admin/articles/page | 分页（含草稿），支持 keyword/status/categoryId |
| GET | /api/admin/articles/{id} | 详情（草稿可见） |
| POST | /api/admin/articles | 保存（新增或更新），标签名不存在则自动创建 |
| PUT | /api/admin/articles/{id}/status | 发布 / 下架（body: {"status":"PUBLISHED"}） |
| PUT | /api/admin/articles/{id}/top | 置顶切换（query: isTop=true/false） |
| DELETE | /api/admin/articles/{id} | 删除（级联删除关联与评论） |

## 四、分类与标签

| 方法 | 路径 | 权限 |
|------|------|------|
| GET | /api/categories · /api/tags | 公开 |
| POST / PUT / DELETE | /api/admin/categories、/api/admin/tags | 管理员（删除前校验引用） |

## 五、评论 `/api/comments`

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | /api/articles/{articleId}/comments | 已通过评论（前台） | 公开 |
| POST | /api/comments | 发表评论；游客需 nickname；返回落库状态 `PENDING`（待审核）或 `APPROVED`（直接展示） | 公开 |
| GET | /api/admin/comments | 分页，status 过滤 | 管理员 |
| PUT | /api/admin/comments/{id}/status | 审核：APPROVED / REJECTED | 管理员 |
| DELETE | /api/admin/comments/{id} | 删除 | 管理员 |

## 六、数据看板 `/api/admin/dashboard`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/admin/dashboard/stats | 文章/评论/用户计数、总浏览/点赞、近 7 天趋势、分类分布 |

## 七、AI 写作辅助 `/api/admin/ai`（仅管理员，需配置 API Key）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/admin/ai/polish | 润色。请求 `{"content":"...", "instruction":"更口语化"}`；响应为 **SSE 流**，`data:` 为增量文本 |
| POST | /api/admin/ai/continue | 续写（SSE 流式，优先插入光标处） |
| POST | /api/admin/ai/summary | 生成摘要，返回字符串 |
| POST | /api/admin/ai/tags | 推荐标签，返回字符串数组（失败返回空数组，不阻断流程） |
| POST | /api/admin/ai/titles | 生成标题候选 5 个，返回字符串数组 |

> API Key 的配置方式见下节「AI 服务配置」——管理端动态维护，保存后即时生效，无需重启。

## 七-A、AI 服务配置 `/api/admin/ai-config`（仅管理员）

管理端动态维护 AI 服务商参数。配置优先级：**数据库（本组接口保存）> 环境变量（application.yml / AI_*）> 代码默认值**。
安全约定：GET 只返回脱敏密钥（前 6 后 4），任何接口不返回明文密钥；修改与恢复默认均记入操作日志。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/admin/ai-config | 获取当前生效配置（含 source=db/env 来源标识、脱敏密钥、向量化实现） |
| PUT | /api/admin/ai-config | 保存配置（完整替换）。body：`{"baseUrl":"...","apiKey":"...","model":"glm-4-flash","temperature":0.7,"timeoutSeconds":60,"embeddingProvider":"auto","embeddingModel":"embedding-3","localDim":512}`。**apiKey 语义**：不传=保持原密钥；空串=清除；新值=替换 |
| DELETE | /api/admin/ai-config | 恢复默认：删除数据库配置，回落环境变量 |
| POST | /api/admin/ai-config/test | 用当前生效配置做一次最小调用，返回 `{"success":true,"reply":"...","latencyMs":457}` |

切换向量化方式（auto/local/remote）或本地维度时，系统自动异步重建全站向量索引，避免旧维度向量与新配置混用。

## 七-B、智能检索与问答（公开）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/articles/{id}/related | 相关文章推荐（语义 0.85 + 标签 0.15 混合排序） |
| GET | /api/search/semantic?q=自然语言 | 语义搜索，返回文章列表 + score 相似度 |
| POST | /api/ai/ask | RAG 站内问答。请求 `{"content":"问题"}`；响应为 **SSE 流**：首事件为引用来源 JSON（`{"type":"sources","items":[...]}`），之后为回答增量文本 |

## 八、用户与日志 `/api/admin`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/admin/users | 用户分页 |
| PUT | /api/admin/users/{id}/password | 重置密码 |
| DELETE | /api/admin/users/{id} | 删除（不能删自己与管理员） |
| GET | /api/admin/logs | 操作日志分页 |

## 错误码约定

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 参数错误（含业务校验信息） |
| 401 | 未登录 / 令牌过期 |
| 403 | 无权限（非管理员访问管理端） |
| 404 | 资源不存在 |
| 500 | 服务器异常 |
| 1001 | 用户名已被占用 |
| 1002 | 用户名或密码错误 |
| 1003 | 账号已被禁用 |
| 2001 | AI 服务未配置 API Key |
| 2002 | AI 服务调用失败 |
| 2003 | AI 返回内容解析失败 |
