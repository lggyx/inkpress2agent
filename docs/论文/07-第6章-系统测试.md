# 第6章 系统测试

## 6.1 测试环境与方法

测试在开发机上完成，环境与开发环境一致：JDK 21、MySQL 8.0 与 Redis 7 运行于 Docker 容器，后端以 jar 包方式启动，前端分别用 Vite 开发服务器和生产构建产物验证。浏览器覆盖 Chrome 与 Edge 最新版本。

测试分三个层次。接口测试用冒烟测试脚本 scripts/smoke-test.ps1 与 JUnit 安全流程测试（SecurityFlowTest，覆盖限流与提示注入审计），对后端接口逐项断言，覆盖认证、文章、评论、点赞、分页边界、检索推荐、AI 降级等场景，每轮提交前都会跑一遍，防止改坏老功能。功能测试按等价类和场景法设计用例，走完整的用户路径。基准测试以 JUnit 实现（RedisBenchmarkTest、SemanticSearchBenchmarkTest），性能数据可一键复现。安全测试针对内容注入、越权访问等场景做定向构造。

## 6.3 智能检索实验

语义检索是本文的重点设计，单独设计了一组实验评估效果。实验方法：构造 5 组自然语言查询，覆盖不同主题，每组取相似度 Top-3 结果，人工判定是否命中预期文章。语料为站内全部 38 篇已发布文章，使用本地特征哈希向量。

表 6-5 语义检索实验结果

| 查询 | Top-1 命中 | Top-1 相似度 | Top-3 内命中 | 判定 |
|------|-----------|------------|------------|------|
| MySQL 配置 | 【MySql】配置项说明 | 0.260 | 是 | 正确 |
| Vue 基础 | 【Vue】基础语法详解 | 0.232 | 是 | 正确 |
| 并查集 | 【蓝桥杯】并查集 | 0.143 | 是 | 正确 |
| Django 入门 | 【Python】Django入门 | 0.288 | 是 | 正确 |
| WebRTC | WebRTC 音视频通话开发教程 | 0.347 | 是 | 正确 |

五组查询的 Top-1 全部命中预期文章，Top-3 命中率 100%。观察结果能看出特征哈希向量的一些特点：查询词与文章标题字面重合度高时（如 WebRTC、Django 入门），相似度分值明显更高（0.29 至 0.35）；主题词更抽象时（如"并查集"），分值降到 0.14 左右，但排序依然正确——说明 bigram 特征对中文短文本的主题区分是有效的。同时也能看到它的局限：第三名之后会混入相关领域但非目标的文章（如查 MySQL 时第三名是蓝桥杯题解），这是无语义泛化的必然结果，配置远程 Embedding 后这类噪声会减少。

相关文章推荐方面，以文章 1 为例，推荐结果前三篇均为动态规划系列文章，混合排序把同系列内容聚拢的效果符合预期。

## 6.4 接口冒烟测试

冒烟测试脚本覆盖 26 项断言，全部通过。测试项包括：文章分页、热门文章、归档、详情与浏览量有效性、登录与令牌、错误密码、注册链路（注册、登录、清理）、无令牌越权、看板统计一致性、管理端分页、文章保存、超长标签拦截、草稿 404、发布流转、游客评论与审核、点赞去重、分页上限、相关文章、语义检索、AI 未配置降级，以及测试数据的清理。

这套脚本的价值不仅在测试本身。项目迭代过程中，每一次改动后跑一遍 26 项断言， regressions 在提交前就会被抓住——开发期间实际拦下过几次问题，比如点赞接口的权限配置错误、文章数量变化后过时的断言。

## 6.5 兼容性测试

前台页面在 Chrome 与 Edge 最新版本下验证通过。响应式方面，三个断点分别验证：宽屏（大于 1280 像素）下详情页为正文加右侧目录的两栏布局；中等屏幕折叠为单栏，目录收为顶部卡片；移动宽度下文章卡片改为纵向排列。3D 视差和触摸交互在触屏设备上自动禁用，避免误触。

## 6.6 本章小结

测试结果表明，系统功能完整、边界稳健、降级行为符合设计。26 项冒烟断言全绿，语义检索五组查询 Top-1 全部命中。AI 模块在无密钥环境下的降级提示明确，配置密钥后即可完整验证。
