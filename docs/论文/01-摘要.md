# 摘 要

随着互联网内容创作的普及，越来越多的个人写作者开始重视对内容数据的自主掌控。托管式平台虽然降低了发布门槛，但排版受限、数据导出困难、风格同质化等问题逐渐显现。与此同时，以大语言模型为代表的生成式人工智能在文本润色、摘要提取等任务上已达到可用水平，且调用成本大幅下降，为写作流程的智能化提供了新的可能。

本文设计并实现了一个基于 Spring Boot 与 Vue 的个人博客与文章管理系统 InkPress。系统采用前后端分离架构：后端以 Spring Boot 3.3 为框架，通过 MyBatis-Plus 访问 MySQL 8.0 数据库，使用 Redis 7 承担热点文章缓存、浏览量计数与点赞去重，采用 Spring Security 结合 JWT 实现无状态认证；前端基于 Vue 3 组合式 API 与 Vite 构建，使用 Element Plus 组件库、Vditor 编辑器和 ECharts 图表库。在功能层面，系统实现了文章管理、分类标签、评论互动、数据看板等博客核心模块，并将大语言模型能力封装为可插拔的写作辅助模块，提供润色、摘要生成与标签推荐三项功能。针对工程实践中遇到的问题，论文给出了具体方案：文章浏览量采用 Redis 计数加定时回写以缓解高频写入；Markdown 正文渲染前经过白名单净化以防止脚本注入；AI 调用适配 OpenAI 兼容协议，通过统一接口屏蔽不同模型服务商的差异。

论文按照软件工程流程组织，完成了需求分析、系统设计、编码实现与系统测试全过程。测试结果表明，系统功能完整、运行稳定，达到预期设计目标，AI 辅助模块在未配置密钥时具备明确的降级提示。

**关键词：** 个人博客；Spring Boot；Vue.js；JWT 认证；Redis 缓存；大语言模型

# Abstract

With the popularization of online content creation, individual writers are paying increasing attention to the ownership of their content data. Hosted platforms lower the barrier to publishing, yet problems such as restricted formatting, difficult data export and stylized homogeneity have gradually emerged. At the same time, generative artificial intelligence represented by large language models has reached a usable level in tasks such as text polishing and summarization, and the cost of invoking these models has dropped significantly, making intelligent assistance in the writing process feasible.

This thesis designs and implements InkPress, a personal blog and article management system based on Spring Boot and Vue. The system adopts a separated front-end and back-end architecture. The back end is built on Spring Boot 3.3, accesses a MySQL 8.0 database through MyBatis-Plus, uses Redis 7 for hot-article caching, page-view counting and like deduplication, and implements stateless authentication with Spring Security and JWT. The front end is built with Vue 3 Composition API and Vite, using Element Plus, the Vditor editor and ECharts. Functionally, the system provides article management, categories and tags, comment interaction and a data dashboard, and packages large language model capabilities as a pluggable writing assistant offering polishing, summary generation and tag recommendation. For engineering problems encountered in practice, concrete solutions are proposed: page views are counted in Redis and written back periodically to relieve high-frequency writes; Markdown content is sanitized against a whitelist before rendering to prevent script injection; AI invocation adapts to the OpenAI-compatible protocol, hiding provider differences behind a unified interface.

The thesis follows the software engineering process, covering requirement analysis, system design, implementation and testing. Test results show that the system is functionally complete and stable, meeting the expected design goals, with a clear degradation notice when the AI module is unconfigured.

**Keywords:** personal blog; Spring Boot; Vue.js; JWT authentication; Redis cache; large language model
