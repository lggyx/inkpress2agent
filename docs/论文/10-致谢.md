# 致 谢

论文写到这里，四个月的毕业设计也快要收尾了。趁这个机会，把该谢的人谢一遍。

最要谢的是我的指导教师。从开题选题被否掉三次，到中期检查前帮我理清检索模块的设计思路，老师每次都给出具体的意见，而不是泛泛地说"再改改"。开题报告前前后后改了五版，老师一遍遍看，连参考文献的格式错误都指了出来。没有这份耐心，论文走不到今天。

谢我的同学们。宿舍老三帮我看了前端 3D 视差的代码，指出了 transition 和 transform 冲突的问题；小李在我被 SSE 解析的空格 bug 折磨了一个下午之后，一句话点醒了我。毕设群里大家分享的踩坑记录，帮我少走了不少弯路。

谢家人。这几个月我作息不太规律，论文攻坚那几周经常熬到凌晨，家里没有一句抱怨，只是每次打电话都问一句"饭吃了没有"。

最后谢一下这个题目本身。做毕设之前，我以为自己已经会写 Web 应用了；真正把认证、缓存、检索、流式输出一个个踩过去，才知道之前的"会"只是"用过"。这个项目留下的不只是几万行代码和一份论文，还有一套"遇到问题先查官方文档、再动手"的习惯，这个大概比分数更值钱。
