# 论文编写说明

按学校《毕业论文（设计）稿模板（2025）》格式编写。

- 模板：`tmp/template/docx/thesis-template.md`（pandoc 提取自学校模板）
- 格式要求：章标题黑体小2号、节标题黑体小三、条标题黑体4号、正文宋体小4号1.25倍行距；摘要黑体小二号居中；关键词宋体小四；目录黑体小4+宋体小4；参考文献 GB/T 7714
- 章节文件：`01-摘要.md` ~ `10-致谢.md`
- 工程图：`docs/diagrams/png/`（论文插图用）

## 章节结构

| 文件 | 内容 |
|------|------|
| 01-摘要.md | 中文摘要 + 关键词 + Abstract + Keywords |
| 02-第1章-绪论.md | 研究背景 / 目的意义 / 国内外现状 / 研究内容 |
| 03-第2章-相关技术.md | Spring Boot / Vue / MySQL / Redis / JWT / 大模型 / 开发环境 |
| 04-第3章-需求分析.md | 可行性 / 功能需求（用例）/ 非功能需求 |
| 05-第4章-系统设计.md | 总体架构 / 功能模块 / 数据库设计 / 接口设计 |
| 06-第5章-系统实现.md | 开发环境 / 核心功能实现（认证、文章、AI、缓存、评论）/ 页面实现 |
| 07-第6章-系统测试.md | 测试环境与方法 / 功能测试 / 结果分析 |
| 08-结论.md | 工作总结 / 不足与展望 |
| 09-参考文献.md | GB/T 7714 格式 |
| 10-致谢.md | 致谢 |
